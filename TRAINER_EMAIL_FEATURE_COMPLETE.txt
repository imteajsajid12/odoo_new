                          TROUBLESHOOTING

ISSUE 1: Button Not Visible
  Solution: Ensure trainer is assigned and event is saved
  Steps:
    1. Assign trainer to event
    2. Save event
    3. Refresh browser (Cmd+Shift+R)

ISSUE 2: Modal Not Opening
  Solution: Check browser console, restart Odoo
  Steps:
    1. Open browser DevTools (F12)
    2. Check Console tab for errors
    3. Restart Odoo: bash start-odoo.sh --dev

ISSUE 3: Email Not Sent
  Solution: Check email configuration
  Steps:
    1. Verify outgoing mail server settings
    2. Check event chatter for error messages
    3. Check Odoo logs: tail -f odoo.log

ISSUE 4: Pre-filled Content Missing
  Solution: Ensure event is saved and fields populated
  Steps:
    1. Save event completely
    2. Verify trainer is assigned
    3. Check event details are filled
